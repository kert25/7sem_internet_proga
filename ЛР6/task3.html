Задание 3. Кодовое слово и разница между visibility: hidden и display: none

Для того, чтобы узнать кодовое слово, скройте элементы со следующими id: code, winter, sky, frog, forest, cloud, hide.

Одна и та же разметка показана дважды. Скрываемые фрагменты помечены атрибутом data-word: это позволяет применить оба свойства к одинаковому набору элементов и не дублировать идентификаторы на одной странице.

Вариант 1 — visibility: hidden

БАДЖЛМЖТЬАЗПШНЙРО

Скрытые буквы не видны, но их место осталось — между видимыми символами сохраняются промежутки.

Вариант 2 — display: none

БАДЖЛМЖТЬАЗПШНЙРО

Скрытые буквы удалены из потока — оставшиеся символы сдвинулись и прижались друг к другу.

В обоих вариантах остаются видимыми символы А, Л, Т, А, Й, которые и образуют кодовое слово — «АЛТАЙ».

Разница между свойствами

Свойство Видимость Место в потоке Влияние на соседние элементы
visibility: hidden элемент не отображается сохраняется (размеры блока остаются) соседние элементы не сдвигаются, на месте скрытого остаётся «дыра»
display: none элемент не отображается не сохраняется (элемент полностью исключается из потока) соседние элементы занимают освободившееся место

Также различаются возможности переключения: у display помимо none есть значения block, inline, inline-block и flex, меняющие способ отображения элемента; visibility отвечает только за видимость (visible, hidden, collapse). Оба свойства не удаляют элемент из DOM: он остаётся доступен из JavaScript и может быть показан снова.
