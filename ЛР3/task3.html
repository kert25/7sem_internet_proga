Задание 3. Определение координат с помощью геолокации

HTML5 Geolocation API позволяет клиентскому веб-приложению с согласия пользователя запрашивать текущие географические координаты устройства через объект navigator.geolocation.

Теоретические сведения

Основной метод API: navigator.geolocation.getCurrentPosition(success_callback, error_callback, options).

  • coords.latitude — географическая широта (в градусах от -90 до 90);
  • coords.longitude — географическая долгота (в градусах от -180 до 180);
  • coords.accuracy — радиус погрешности измерений в метрах;
  • coords.altitude — высота над уровнем моря (в метрах);
  • timestamp — метка времени фиксации координат.
