Задание 4. Рисование на элементе <canvas>

В соответствии с методическими указаниями на холсте <canvas> нарисован домик с элементами окружающего ландшафта (солнце, облака, забор, дерево). В работе применены:

  • Простые геометрические фигуры: прямоугольники (fillRect, strokeRect, rect) и окружности/дуги (arc);
  • Составные пути (контуры): beginPath, moveTo, lineTo, closePath;
  • Линейные градиенты: createLinearGradient с контрольными точками addColorStop (небо, земля, крыша);
  • Тени: shadowOffsetX, shadowOffsetY, shadowBlur, shadowColor для придания объёма стенам и подписи;
  • Текстовая подпись: метод fillText с указанием шрифта font (ФИО автора работы).
Ваш браузер не поддерживает элемент HTML5 canvas.

Ключевые фрагменты программного кода рисования

Инициализация контекста двухмерной графики: const ctx = document.getElementById('draw').getContext('2d');.

Для создания градиента неба применён метод: const sky = ctx.createLinearGradient(0, 0, 0, 320); с переходом от лазурного цвета к светло-голубому у горизонта. Крыша домика нарисована треугольным контуром через последовательность moveTo и lineTo с тёмно-красным градиентом.
