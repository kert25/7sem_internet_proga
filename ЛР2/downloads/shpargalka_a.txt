ШПАРГАЛКА ПО ТЕГУ <a>
====================

<a href="URL">текст ссылки</a>     — основная форма ссылки

АТРИБУТЫ
--------
href="..."        — адрес перехода (URL)
                  - относительный:  "inner.html", "../ЛР1/first.html"
                  - абсолютный:     "https://site.ru/blog/index.html"
                  - якорь:          "#part1" или "text.html#part1"
                  - e-mail:         "mailto:admin@site.ru"
                  - e-mail с темой: "mailto:admin@site.ru?subject=Тема"
title="..."       — всплывающая подсказка
target="..."      — окно открытия ссылки:
                    _blank  — в новом окне (вкладке)
                    _self   — в текущем окне (по умолчанию)
                    _parent — во фрейм-родитель (устарело)
                    _top    — в полное окно браузера (устарело)
download          — скачать файл, а не открывать его
                  (браузер может игнорировать, если для типа
                  файла есть стандартная обработка)

ССЫЛКА-ЗАГЛУШКА
---------------
<a>текст</a>      — ссылка без href; используется, например,
                    чтобы показать текущую страницу в меню

ЯКОРЬ (МЕТКА)
-------------
<a id="part1"></a>          — современный способ (атрибут id)
<section id="part1">...</section> — метка на любом элементе
<a name="part1"></a>        — классический способ (устаревает)

ССЫЛКА-КАРТИНКА
---------------
<a href="index.html"><img src="image.png" alt="..."></a>

Файл создан в рамках лабораторной работы №2.
