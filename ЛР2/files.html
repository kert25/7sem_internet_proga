Файлы для скачивания

Файлы лежат во вложенной папке downloads. В ссылках используется атрибут download — он сообщает браузеру, что файл нужно скачать, а не открывать прямо на странице.

ФайлОписание
rezjume.txt Резюме (учебное, текстовый формат)
plan_kursa.txt План лабораторных работ курса
shpargalka_a.txt Шпаргалка по тегу <a>

Сравнение поведения

Текстовые файлы браузер умеет открывать прямо на странице. Ссылка резюме без атрибута download откроет файл в текущей вкладке, а все ссылки выше — скачают его.

Замечание: если для типа файла существует стандартная обработка, браузер может игнорировать атрибут download.
