Заполните все необходимые поля анкеты. Форма демонстрирует работу базовых элементов HTML, современных типов input HTML5, атрибутов валидации и перехват данных обработчиком.

⚠️ Ошибки проверки формы (HTML5 Constraint Validation API)

Форма отклонена браузером до устранения следующих несоответствий правилам валидации:

  • Имя (ФИО студента): Поле обязательно для заполнения (ограничение required, флаг valueMissing).
  • E-mail адрес: Введено значение неверного формата (ограничение type="email", флаг typeMismatch).
  • Номер телефона: Значение не соответствует регулярному выражению pattern="\+7-\d{3}-\d{3}-\d{4}" (флаг patternMismatch).
